# iOS 国外加速

普通 DEV 浏览模式可以在「设置 → 国外加速」导入已核对的 Xray Standard 域名清单，然后开启「自动加速清单内网站」。默认关闭。开关只影响此普通浏览作用域的规则，重启后保留。私密和其他浏览作用域，以及 Alpha、Beta 和 Release，均不提供这个设置。

## 清单

使用 [XTLS/Xray-rules-dat 的 Standard 数据](https://github.com/XTLS/Xray-rules-dat/tree/205ad588659c76e5d78fba92f527146d39fecb80)中 `blocked-in-cn` 的验收清单。导入文件为每行一个 ASCII 主机，去重排序后有 4,372 个明确域名。规范化为 ASCII 排序、每条以 LF 结束后，SHA-256 为 `84a004adf2537fde3befb724fe77512cf3a4acb1df8ec350cd898a6cf8428374`。其余 17 项上游规则为单标签、IP、子串或正则表达式，均未纳入此清单。用于验收的流行、常用、一般、不常用四组共用同一开关。

应用验证导入文件后在本机存储。导入失败会保留已有清单和开关状态。已开启后，如果持久存储无法恢复核定清单，新导航继续遵守已有的明确选路，其他可能受影响的导航暂停，直到再次导入或关闭开关。

## 选路和撤销

对没有更明确选路的顶层 HTTP(S) 地址，精确命中才沿用 Access 的准备、绑定和失败关闭路径。该页面内的资源随绑定的 WebKit 数据存储发送。每个子域独立匹配。原有逐站选择优先，其他网站继续按原有规则选路。

关闭开关时，使用现有文档退役流程停止失去授权的绑定。仍有独立授权的页面保留其授权。切换不会自动重发导航。

# Access Options SDD · iOS、Android 和 macOS

2026-11-20 · 三端都提供本应用的 Access Options 设计。以 [fork main `c5b4257a`](https://github.com/quinn521/aegis-browser/tree/c5b4257a221b7d4434a113d2c13d870139b8d6fa) 为基线。入站选择的资格、时限和失败处理采用 [回环合同](app-inbound-contract.zh-CN.md)。平台交付入口为 [iOS](ios-app-inbound-sdd.zh-CN.md)、[Android](android-app-inbound-options-sdd.zh-CN.md) 和 [macOS](macos-app-inbound-sdd.zh-CN.md)。

## 用户操作

在内部构建的普通窗口中，用户打开 Access Options，选择要编辑的连接 Profile，在“本地入站”中保留“自动”或锁定 HTTP/SOCKS5，检查端口，点击“应用”。草稿、已保存值和当前网页的实际连接分别显示。例如已保存“自动”，当前页可显示“HTTP · 当前系统的 SOCKS5 尚未准入”。未打开受影响网站时只需保存意图；打开该网站时才按策略建立绑定。

| 设置或状态 | 交互与数据合同 |
| --- | --- |
| 本地协议 | 自动为新配置的默认偏好，顺序为无认证 SOCKS5、无认证 HTTP。显式 HTTP 或 SOCKS5 只执行所选协议。显示不可用原因，并允许用户返回修改草稿。本地没有用户名、密码或代理登录窗口 |
| 监听端口 | 默认由应用分配。内部指定端口仅接受十进制 1–65535，地址显示为只读数值回环。指定值是端口偏好，实际端口来自当前监听。被其他作用域占用或退役未确认时显示冲突，保留保护意图，不抢占、不偷偷换口 |
| Profile 与站点 | Profile 持有稳定 ID、版本、上游配置或授权引用以及本地入站偏好。站点规则另行决定原连接、强制保护或经授权的可选恢复。规则中的自动切换选择 Profile；Profile 内的“本地协议 · 自动”只在登记时选择入站。已有企业/安全策略优先 |
| 实际连接 | 当前页面或标签显示 Profile、准备/已连接/失败状态、实际运输与回退原因。内部详情可看本次实例代次和端口。没有绑定时显示“尚未建立连接”。账户、套餐和上游失败来源单列 |
| 界面、文件和诊断 | 入口包含常规与界面/主题、内置或自定义 Profile、站点与切换规则、导入/导出、诊断及账号/用量入口。各端沿用已有支持的 Profile 类型与匹配范围。受限类型显式拒绝，不能因导入文件而获得执行权限 |

## 发布和持久化

草稿属于当前编辑窗口。协议或端口变更先展示受影响的活跃页面，Discard 回到最近提交版本，禁止触发网络操作。Apply 绑定 Profile、baseRevision 和 operationID，通过平台唯一发布者比较版本并校验整个候选。另一窗口抢先提交时返回冲突并保留草稿以便重新比较；相同操作重试查询先前结果。开始退役后出现超时或不确定结果时保持保护屏障，重开页面先核对已提交版本。

普通 Profile 持久化协议偏好、端口偏好和规则引用。私密草稿与运行状态仅随对应作用域存活。兼容版本的导入先预览差异并标示需重新绑定的上游引用，经明确 Apply 后生效；重复 ID、未知格式、端口越界、旧的必需本地凭据与不支持的协议给出原因。导出已提交的允许字段，剔除密码、订阅 URL、实际端口、会话和私密记录。重置使用同一发布事务，不能清掉已有保护屏障。主题变化只影响界面呈现。

编辑、保存和实际激活使用不同判据。可信内部 Debug/Alpha 以包身份和平台能力开放完整编辑器。节点或 Android 产品接线尚未就绪时可编辑允许的配置，应用须显示“已保存，连接不可用”或准确的未提交错误。Beta/Release 继续提供该渠道已授权的简洁网站与用量入口，未知或身份冲突的构建拒绝高级配置的页面、文件、命令和激活。强制保护缺少端点时不能加载原连接。

## 三端交付验收

| 平台 | 从真实设置入口验证 | 运行证据与执行工单 |
| --- | --- | --- |
| iOS | iPhone 和 iPad 原生设置、两窗编辑冲突、VoiceOver 和最大字体；Apply 导致旧文档换库时预览影响并确认 | 对照选中的 DataStore、实际代理、跨源收件和退役结果。[iOS #208](https://github.com/gcsagroup/aegis-browser/issues/208) |
| Android | 原生 Aegis 设置 Fragment，TalkBack、旋转、系统返回、多窗口与被系统回收后的恢复；UI 不把共享核心能力位当成已安装路线 | 对照 Android APK 的 Profile、NetworkContext ACK、NetLog 和真实设备收件。[Android #210](https://github.com/gcsagroup/aegis-browser/issues/210) |
| macOS | 工具栏当前网站面板和可信 WebUI，键盘、VoiceOver、双窗口、直接 URL/消息和渠道门。切换协议不重放当前业务请求 | 对照浏览器发布回执、实际 proxy chain 和受控出口。[macOS #209](https://github.com/gcsagroup/aegis-browser/issues/209) |

每个平台至少验证自动优先 SOCKS、自动在绑定前选 HTTP、固定 HTTP、固定 SOCKS 不可用、两者都不可用、端口冲突、保存失败、退出私密和撤销后的零直连。界面测试使用明确的状态来源，产品准入必须补齐同一候选的真实运行证据。

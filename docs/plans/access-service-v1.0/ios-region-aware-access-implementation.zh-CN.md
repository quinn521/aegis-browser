# iOS 按上网地区选路与网站位置隐私实施方案

实施规范 · 2026-11-28 · 基线 `0755753e`

新装默认为手动并沿用浏览器的原连接。合格的失败可单次加速重试。启用自动时默认全量，两地方向均开启，大陆以外在前。用户在「中国大陆」和「中国大陆以外」之间手选当前上网地区。

跨区命中规则时加速，同区优先原连接。自动模式下，上海访问豆瓣先走原连接，新加坡访问则在命中大陆规则时直接加速。全量覆盖已批准的清单。基于 IP 选择地区列为后续版本。首版把流量管理归入网络加速，网站级位置保护同时使用服务出口 IP 和阻止网页索取设备坐标。

## 二、设置与路由合同

- **设置 → 网络加速 → 当前上网地区**。选项为「中国大陆」「中国大陆以外」，后者包含港澳台。新安装为未选择，普通浏览及手动失败重试可以先用。首次启用自动时复用这个选择入口，也可在旅行后修改。选择地区不请求设备定位或远程 IP 定位。
- **设置 → 网络加速 → 网站加速**。顶层只有手动、自动。自动下面显示全量、按分类，首次预选全量。依次展示「大陆以外网站」「中国大陆网站」。新用户首次编辑分类时两地可用分类全选，保存过的子集和空选均按原值恢复。全量保留分类草稿。首次启用把地区、范围、规则版本放在同一次确认中，取消保留此前策略。后续扩大授权沿用现有确认。
- **设置 → 网络加速 → 流量管理**。使用现有订阅用量和刷新状态，区分未知、已用尽及共享额度。此入口按自己的可用条件展示，私密窗口继续隔离普通账户用量。现有内部连接选择保留渠道约束。
- **内测 Beta 节点清单**。签名包可提供 3X-UI 和下载目录的测试节点。首项固定为绑定订阅的 3X-UI VLESS TCP/REALITY 线路。同一身份的线路须通过实时订阅授权，其他测试身份由测试者手动切换。缺失的用量字段显示 `--`。切换时结束上一条线路的会话，避免继续使用之前的出口或显示之前的用量。普通 Beta 的网站加速可用性沿用原规则。
- **设置 → 隐私保护 → 隐藏地理位置**。展示当前可信网站、本站开关、服务连接和网页定位状态，与地址栏、当前网站面板共用同一状态源。内部页或无可确认目标时提示先打开网站。

下表适用于普通窗口、无本站覆盖、规则有效、域名在相应规则范围内。这里的「原连接」沿用该标签原有的 WebKit 数据存储和系统网络设置。

| 模式与当前上网地区 | 大陆以外方向规则命中 | 中国大陆方向规则命中 |
|---|---|---|
| 手动，任一地区或未选 | 原连接，合格的失败可手动加速重试 | 同左 |
| 自动，人在中国大陆 | 加速 | 原连接 |
| 自动，人在中国大陆以外 | 原连接 | 加速 |

手动模式下显示加载失败卡片及可选的加速打开提示。常用字号下，单个普通重试按钮与失败摘要同排。点击信息图标展开错误详情。

1. 全量纳入两个方向已批准的全部规则，包括海外全量允许的未分类项。按分类只纳入勾选分类原本可匹配的范围。一个主机同时属于两张用途清单时，按当前地区找到对应的跨区授权，依该授权的例外和版本求值。界面排序不参与决策。
2. 安全和管理限制先行。本站显式连接选择优先于地区规则。开启双重隐私时，同一事务将本站改为要求受保护连接并启用定位阻止。显式改回原连接时必须同步说明并撤销这项 IP 保护。仅撤销隐私授权后，其他独立加速授权单独求值。普通、私密和不同私密会话按原作用域隔离。
3. 经有效规则确认为未命中且无其他授权的网站走原连接。本地、局域网和不合格目标退出自动分类。已要求保护或可能处于已批准范围但账本损坏、过期、保存中断、范围暂无法确定的请求，按现有等待或失败语义处理。远程暂停或排除项只撤回其对应规则来源。
4. 地址栏、页面内顶层导航、逐跳重定向和手动重试统一取同一份策略。页面内资源随所属 WebKit 存储。切地区、切模式或撤回规则后，作废旧待发操作并重新求值，及时停止已失去授权的旧文档继续发送。保持仍有独立授权的连接。安全请求可按新策略重新加载，表单留给用户处理。[WebKit 选路与撤回](ios-overseas-acceleration.zh-CN.md) · [精确主机存储](ios-exact-host-store-sdd.zh-CN.md)

## 三、实施顺序

| 步骤 | 实现位置与动作 | 交付判据 |
|---|---|---|
| 1. 冻结规则与定位能力 | 修订国内、海外、位置隐私三份产品合同，补充方向映射和上表。并行做真实 WKWebView 定位能力试件。iOS 27+ 使用公开回调按受保护文档拒绝所有 frame。对 18.4 至 26.x 验证系统强制拒绝的实际条件，包括已授予权限的情形。 | 产出每个支持层级能承诺的能力。旧系统若无法证明可靠拒绝，双重保护入口明确提示不可用，已要求双重保护的导航保持暂停。旧系统实现不依赖私有 API 或仅靠注入 JavaScript。 |
| 2. 统一持久化与迁移 | 在 `AccessGeoSiteCache` 现有账本上保存地区、顶层模式、自动范围、两地分类及批准版本。复用原有快照、水位、撤回记录和 owner。用同一笔耐久提交发布新设置与有效授权。 | 冷启动、磁盘写入失败、切窗、重启后选择一致。版本确认失效或用户取消时，没有一侧提前生效。 |
| 3. 接通选路与一次重试 | 在 `AccessHostStoreCoordinator` 汇合手动、地区、两路规则和本站授权。重试临时授权绑定作用域、标签、失败请求和策略版本，在主文档提交时结束顶层授权。已提交文档中的资源继续共用其受管存储。复用现有发布器、票据、存储隔离和 15 秒准备预算。 | 配置了服务的新装手动首次访问仍走原连接。只重放无请求体的合格 GET/HEAD，保留方法。重复点击合并一次准备，取消、同标签发起新导航或切地区后，旧回调不能发送。证书、策略阻断及不安全提交沿用各自处理。 |
| 4. 完成双重隐私 | 将已确认的本站隐私意图传入 `BrowserTab` 的文档创建、存储切换和 WebKit 权限决定。开启时先停止旧文档和已有定位监听，再创建受保护文档。同一站点原已因加速而使用受管存储时，也要更新其定位策略。 | 网页定位由 iOS 27 起的 WebKit 权限回调拒绝。受保护页面使用 WebKit Lockdown 关闭 WebRTC 和 WebTransport，页面发起的顶层跳转只允许同站或已单独启用位置保护的目标。页面交给独立下载器的请求暂停。两层齐备才显示已保护。服务连接中断或定位能力失效时保护暂停。 |
| 5. 调整设置与用量 | 重排 `BrowserSettings` 两个分类，调整 `OverseasAccelerationSettingsView`、`AccessUsagePage`、测试 Profile 的旧入口文案。复用站点开关模型和 `AccessSubscriptionUsageSession`。 | 大陆以外在前，手动时收起自动选项。设置、地址栏、当前网站显示同一实际状态。筛选网站加速的 DEV／已启用内部 Alpha 条件独立于流量管理。完成资源语言、动态字号、VoiceOver 和私密隔离回归。 |

**迁移映射。** 新装和旧手动且两地自动范围未开启的用户进入手动。旧智能的子集、空选、海外独立开关、海外全量及本站覆盖逐项保留。对于旧手动但已批准海外、或旧智能但尚未选择地区的安装，继续执行仍可证明的旧授权，界面提示选择地区。用户确认后一次转换成新的地区策略，保留主动关闭、撤回和排除记录。升级本身不给任何新主机授权。测试包含写入中断后再次升级，以及从全量切回已保存的空分类。

## 四、验收矩阵

| 场景 | 需要观察到的结果 |
|---|---|
| 两个地区 × 手动／全量／分类 | 用大陆方向、大陆以外方向、仅全量命中、两组重叠、未命中五类受控样本，比对原连接和受管入口收据。选中的出口收到本次请求，另一条路径计数为零。另测海外排除、非 443、失效快照和仅在一个方向签发的授权。 |
| 失败重试与策略变化 | 同域开两个标签，单击只恢复原标签的原 URL。HEAD 仍为 HEAD，POST 零重放，第二个标签和下次独立访问没有继承授权。切地区、取消启用、旧入口迟到、撤回或关窗后无旧请求。 |
| 出口 IP 与失效 | 受控 HTTPS 服务记录受保护请求的出口 IP，与原连接对照。保持已有原页面时开启、开启后切地区、断开服务或耗尽额度，检查后续请求无原 IP 回退。按冻结规范单验 WebRTC 等另有网络路径的能力，受保护上下文须阻止可暴露原 IP 的旁路。[Access 执行合同](spec.zh-CN.md) |
| 网页设备定位 | 在有已知测试坐标的环境中验证正对照，再测主页面、同源与跨源 frame 的单次定位和持续定位。覆盖提示前、曾授权、监听进行中才打开保护、后退恢复、新窗口。受保护文档收到权限拒绝，持续监听收不到后续坐标和缓存坐标。普通会话和私密会话互不借用授权。 |
| 界面、用量与真机 | 核对两个设置入口、地区修改、国内外顺序和三处隐私状态。验证额度未知、耗尽与刷新，以及私密页隔离。模拟器收据验证选路，同一候选构建在 iPhone 上验证实际服务出口和设备定位。要承诺大陆内外均可用，分别记录对应网络环境及线路证据。 |

现有测试入口可以直接扩展。[WebKit 路由](../../../apps/ios/Tests/AegisTests/AccessHostRecoveryWebKitTests.swift) 已有首次公网访问及旧国内手动／海外独立生效用例，增加适用新模式的普通窗口，并保留其他渠道的对照。[恢复协调器](../../../apps/ios/Tests/AegisTests/AccessProxyRecoveryCoordinatorTests.swift) 增加一次点击不改变共享站点意图的回归。[GeoSite 账本](../../../apps/ios/Tests/AegisTests/AccessGeoSiteCacheTests.swift) 增加升级、撤回和写入中断回归。[设置 UI](../../../apps/ios/Tests/AegisUITests/SettingsLayoutUITests.swift) 覆盖从旧入口迁移、区域顺序、持久化和两层保护状态。

## 五、实施验证

- iOS 27.0 模拟器以独立的原连接和加速 HTTPS 监听器验证手动首次访问、跨区加速和同区原连接。加载失败后的单次重试保留 HEAD，同域其他标签不继承授权。[WebKit 路由与重试](../../../apps/ios/Tests/AegisTests/AccessHostRecoveryWebKitTests.swift)
- iOS 27.0 的受保护文档在 WebKit 权限层拒绝单次定位和持续定位，覆盖主页面、同源及跨源 iframe。模拟定位对照使用临时测试包的定位用途声明，使开启保护前的监听收到坐标。启用保护后旧文档退役，WebKit Lockdown 停用 WebRTC 和 WebTransport。[位置保护测试](../../../apps/ios/Tests/AegisTests/AccessHostRecoveryWebKitTests.swift)
- iOS 26.5 模拟器验证既有网站保护授权保持暂停，普通和私密授权彼此独立。连接模式和用量界面仍可使用。iOS 设备目标通过未签名构建。[旧系统保护与会话隔离](../../../apps/ios/Tests/AegisTests/AccessProxyRecoveryCoordinatorTests.swift)
- 设置界面验证全量默认、海外在前、两地默认开启、分类清空后重启恢复及取消确认。最大动态字号可以操作两地设置，流量管理可单独进入。14 种资源语言通过编译与查询核对。[设置 UI 回归](../../../apps/ios/Tests/AegisUITests/SettingsLayoutUITests.swift)
- iOS 27.0 扩展回归中，原 GeoSite 用例在禁止跨存储重放后未观察到同存储 POST。基线 `0755753e` 在同一运行时复现。[旧 GeoSite 写入用例](../../../apps/ios/Tests/AegisTests/AccessHostRecoveryWebKitTests.swift)
- 实际公网出口 IP、iOS 27 真机位置保护及中国大陆内外的网络体验仍需对应设备和真实线路。本次所连接的 iPhone 运行 iOS 26.6.1。
